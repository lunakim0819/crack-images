MOA 데모 수정 가이드 (VS Code 초보용)

이 데모는 인터넷 연결 없이 내 컴퓨터에서만 작동하는 가상 SNS 화면입니다. 어떤 글이나 쪽지도 실제로 전송되지 않습니다.

1. 열기

  1. moa-vscode.zip을 마우스 오른쪽 클릭 → 압축 풀기.
  2. VS Code 실행 → 메뉴 파일 → 폴더 열기(Open Folder) → 압축 푼 moa-vscode 폴더 선택.
  3. 탐색기(파일 창)에서 index.html을 더블클릭하면 브라우저에서 바로 열립니다.
    (선택) VS Code 확장 Live Server를 설치했다면 index.html에서 마우스 오른쪽 → Open with Live Server. 저장할 때마다 자동 새로고침돼요.

2. 폴더 구조

moa-vscode/
├─ index.html          화면 뼈대 (보통 안 고쳐도 됨)
├─ guide.html          지금 보고 있는 가이드
├─ README.md           짧은 설명
├─ css/style.css       색·글꼴·크기
├─ js/data.js          ★ 계정·게시글·답글·알림·쪽지 내용 (주로 여기만 고침)
├─ js/app.js           동작 코드 (화면 전환, 좋아요 등)
└─ assets/images/      ★ 이미지 넣는 폴더
   ├─ sample-avatar.svg     연습용 샘플
   └─ sample-landscape.svg  연습용 샘플

index.html은 js/data.js를 먼저, js/app.js를 나중에 불러옵니다. 이 순서를 바꾸지 마세요.

3. 이미지 추가하기

  1. 사진 파일을 assets/images/ 폴더에 넣습니다 (VS Code 탐색기로 끌어다 놓아도 됨).
  2. 파일 이름은 영어 소문자·숫자·하이픈으로 간단하게: haneul.jpg, sunset-1.png (띄어쓰기·한글 이름은 피하기).
  3. js/data.js에 경로를 적습니다. 경로는 항상 상대 경로 + 슬래시(/): 
    좋음:   'assets/images/haneul.jpg'
안 됨:  'C:\Users\나\Desktop\haneul.jpg'   (내 컴퓨터에서만, 역슬래시 문제)
안 됨:  'assets\images\haneul.jpg'        (역슬래시 \ 대신 / 사용)

사용 가능한 이미지 칸:

어디필드
계정 프로필 사진avatar
프로필 배너banner
게시글 사진image (적으면 이미지 칸 자동 생성, 미디어 탭·뷰어에도 나옴)
답글 사진image

이미지 크기: 게시글·답글 사진은 원본 비율과 크기 그대로 나옵니다. 작은 사진은 확대하지 않고, 글 폭보다 큰 사진만 폭에 맞춰 줄어들며 잘리지 않아요(세로로 긴 사진은 글도 길어짐). 사진 크기를 바꾸고 싶으면 이미지 파일 자체 크기를 바꾸세요. 단, 프로필 사진(원형)·배너·미디어 탭 썸네일(정사각형)은 디자인상 칸에 맞춰 잘리고, 썸네일을 누른 뷰어에서는 전체가 잘림 없이 보입니다.

경로를 비우거나('') 파일을 못 찾으면 자동으로 ‘이미지 없음’ 빈 칸이 보입니다. 화면이 깨지지 않아요.

예시 ① 프로필 사진·배너 (샘플 파일로 바로 연습 가능)

haneul:{ name: '하늘필름', handle: 'haneul_film', avatar: 'assets/images/sample-avatar.svg', banner: 'assets/images/sample-landscape.svg', bio: '필름 카메라로 동네 풍경을 찍어요. 주말 출사 기록.', following: 180, followers: 2430 },

예시 ② 게시글 사진

{ id: 'p1', author: 'haneul', time: '2시간', text: '오늘 한강 노을. 필름 한 롤 다 썼어요.', image: 'assets/images/sample-landscape.svg' },

4. 계정·게시글·답글 추가

모든 id는 서로 겹치면 안 됩니다. 게시글은 p10, p11…, 답글은 r12, r13…처럼 번호를 이어가세요.

계정 추가 (accounts 안에)

minji: { name: '민지의 화분', handle: 'minji_plants', bio: '베란다 식물 키우기 기록', following: 40, followers: 310, avatar: '' },

팔로잉 피드에 보이게 하려면: const followingIds = ['haneul', 'dain', 'yul', 'minji'];

게시글 추가 (posts 안에)

{ id: 'p10', author: 'minji', time: '방금', text: '몬스테라 새 잎이 났어요!', image: 'assets/images/monstera.jpg' },

author에는 계정의 id(예: minji)를 적습니다. 위쪽에 적은 게시글이 피드 위에 보여요.

답글과 답글의 답글 (replies 안에)

{ id: 'r12', rootPostId: 'p10', parentId: null,  author: 'yul',   text: '축하해요!' },
{ id: 'r13', rootPostId: 'p10', parentId: 'r12', author: 'minji', text: '@yul_walks 고마워요!' },
  • rootPostId: 어느 게시글 아래 답글인지 (게시글 id)
  • parentId: 바로 위 답글 id. 게시글에 직접 단 답글이면 null (따옴표 없이)

이렇게 이어 주면 세로선으로 대화가 연결돼 보입니다.

5. 알림·쪽지 기본 내용

알림 (notifications 안에)

{ id: 'n7', type: 'reply', actor: 'yul', target: 'r12', time: '방금' },

type: follow(팔로우, target 없음) · like · mention · reply. target은 게시글/답글 id로, 누르면 그 글로 이동해요.

쪽지 대화 (chats 안에)

{ with: 'minji', messages: [
  { from: 'minji', text: '물 주기 팁 있나요?', at: '2026-11-08T10:00' },
  { from: 'me',    text: '일주일에 한 번이면 돼요.', at: '2026-11-08T10:05' },
]},

from이 'me'면 오른쪽 파란 말풍선, 상대 id면 왼쪽 회색 말풍선. at은 연-월-일T시:분 형식.

6. 색·글꼴 바꾸기

css/style.css 맨 위:

:root{--bg:#000;--line:#2f3336;--text:#e7e9ea;--sub:#71767b;--blue:#1d9bf0;--pink:#f91880;...}

예: 포인트 색을 보라로 → --blue:#8b5cf6. 글꼴은 html,body{ font-family: ... } 줄에서 바꿉니다.

7. 저장하고 확인하기

  1. VS Code에서 Ctrl+S (맥: Cmd+S)로 저장.
  2. 브라우저에서 F5(새로고침). Live Server를 쓰면 자동.

8. ‘원본 내용’과 ‘브라우저 저장 내용’의 차이

data.js는 처음부터 보이는 기본 내용입니다. 반면 화면에서 누른 좋아요·북마크·팔로우·재게시·직접 쓴 글·답글·쪽지는 브라우저(localStorage)에만 저장되고 data.js에는 기록되지 않아요.

그 저장 내용을 지우려면: 화면 하단 MOA 마크(내 프로필) → ‘데모 저장 데이터 초기화’ → 확인. 이 데모가 쓰는 저장값(moa-demo-state-v1) 하나만 지우고, data.js 원본은 그대로입니다.

data.js에서 followingIds를 바꿨는데 팔로잉 피드가 그대로라면, 예전에 저장된 팔로우 상태 때문이에요. 초기화 버튼을 누르세요.

9. 문제가 생기면

증상확인할 것
화면이 통째로 안 나옴data.js 문법 오류일 가능성이 큽니다. 고친 줄에서 쉼표(,) 빠짐, 따옴표 짝 안 맞음, { } [ ] 짝 확인. 브라우저 F12 → Console에 빨간 오류와 줄 번호가 나옵니다.
글 안에 작은따옴표(')가 필요'it\'s'처럼 \' 로 쓰거나, 바깥을 큰따옴표로: "it's"
이미지가 ‘이미지 없음’으로 나옴파일이 assets/images에 있는지, 파일명·확장자 대소문자(Photo.JPG ≠ photo.jpg), / 슬래시, 띄어쓰기 확인.
새 글이 안 보임author 값이 accounts의 id와 정확히 같은지, 팔로잉 탭이면 followingIds에 있는지(또는 ‘추천’ 탭 확인).
답글이 엉뚱한 곳에rootPostId·parentId 오타, id 중복 확인.
고쳤는데 안 바뀜Ctrl+S 저장 후 새로고침했는지 확인. 그래도 안 되면 Ctrl+F5.

이 데모는 혼자 보는 로컬 화면입니다. 실제 계정 연동, 실제 전송, 여러 사람 동기화는 없습니다.
