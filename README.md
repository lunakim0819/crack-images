# crack-images

크랙(Crack, crack.wrtn.ai) 피드와 상세 설명에 넣을 이미지를 올려두는 외부 이미지 호스팅 저장소입니다.

## 이미지 규격 (크랙 고객센터 기준)
- 지원 형식: jpeg, jpg, png, webp, gif
- 최대 용량: 5MB 이하
- 세로로 너무 긴 이미지는 피하고, 정방형 기준을 권장

## 사용 방법
1. 이 저장소에 이미지를 업로드합니다 (예: images/파일명.png).
2. 이미지 주소를 아래 형식으로 만듭니다.
   - https://raw.githubusercontent.com/lunakim0819/crack-images/main/images/파일명.png
3. 크랙 피드나 상세 설명에 마크다운으로 넣습니다.
   - ![이미지 설명](이미지 주소)
   - [![](이미지 주소)](사이트 링크)

## 주의
- 저장소가 공개(Public)여야 외부에서 이미지가 보입니다.
- 파일 이름은 영문, 숫자, 하이픈으로 짓는 것이 안전합니다.
